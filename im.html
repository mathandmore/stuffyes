Sheetdrop

Images over 1 MB are compressed in your browser, then stored as data URLs in your Google Sheet.

Connect your Google Sheet

  1. Create a Google Sheet, then open Extensions → Apps Script.
  2. Paste in Code.gs, run setup once, and approve access.
  3. Choose Deploy → New deployment → Web app. Set Execute as to Me and Who has access to Anyone.
  4. Paste the Web app URL below.

    Use the API

    Your Web App URL is the API. Every response is JSON with ok: true or ok: false and an error.

    RequestWhat it does
    POST uploadStore an image. Body: {"action":"upload","name","dataUrl","key"}. Returns id and deleteToken. Max 1 MB.
    GET ?action=listNewest images with small thumbnails. Optional &limit=24.
    GET ?action=info&id=Name, type, size and date for one image.
    GET ?action=get&id=Everything in info plus the full dataUrl.
    POST deleteBody: {"action":"delete","id","token"}.

    Send POST bodies as text/plain so browsers skip the CORS preflight that Apps Script can’t answer.
